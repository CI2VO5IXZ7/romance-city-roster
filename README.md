## 敏感信息声明

本仓库仅含角色设定、分工与公开/半公开人设。以下内容**禁止入库**：

- Telegram / API / Bot token、OAuth、Cookie、私钥
- `.env`、邮箱明文、订阅链接、节点 UUID/密码
- 内网 IP、Tailscale 节点地址、生产公网暴露细节

密钥与地址只放运行环境私密配置；聊天与仓库展示一律打码。
